# رواسي للمقاولات العامة — صفحة هبوط (سابقة أعمال)

> **ملاحظة:** هذا مشروع تصميمي (Case Study) بُني كسابقة أعمال لعرضها في منصات العمل الحر. اسم الشركة "رواسي" وجميع البيانات (المشاريع، الإحصائيات، الشهادات، بيانات التواصل) **بيانات افتراضية لأغراض العرض فقط** ولا تمثل كيانًا تجاريًا حقيقيًا.

## نظرة عامة

صفحة هبوط عربية (RTL) لشركة مقاولات عامة متخيّلة، مبنية بـ HTML/CSS/JS خالص بدون أي إطار عمل (Framework-free) لضمان أعلى أداء ممكن. هوية بصرية "إنشائية مرتفعة" (Elevated Structural) مستوحاة من اتجاهات 2026: تسلسل هرمي مبالغ فيه للعناوين (Exaggerated Hierarchy)، تخطيط غير متماثل يكسر الشبكة عمدًا، نسيج حبيبي (grain) على الأقسام الداكنة، وتصوير فوتوغرافي حقيقي معبّر لمواقع الإنشاءات بدل الأيقونات التجريدية.

**رابط الموقع المباشر:** https://rawasi-web-production.up.railway.app

## الأقسام

- رأس صفحة لاصق يختفي عند التمرير للأسفل ويظهر عند التمرير للأعلى
- Hero بعنوان ضخم يتكشف سطرًا سطرًا + صورة موقع إنشاءات حقيقية بإطار مكسور الشبكة + عدّادات إحصائية متحركة
- شريط ثقة (Marquee) بالقطاعات المخدومة
- من نحن، خدماتنا (Bento Grid)، منهجية العمل (Timeline)، لماذا رواسي
- أعمالنا: شبكة مشاريع قابلة للتصفية حسب التصنيف
- آراء العملاء، الأسئلة الشائعة (Accordion أصلي عبر `<details>`)
- نموذج تواصل مع تحقق فوري من الحقول (تجربة أمامية فقط — بلا Backend فعلي)
- تذييل غني بالروابط والنشرة البريدية

## التقنيات

- HTML5 دلالي + CSS مخصص (Custom Properties، Logical Properties لدعم RTL، Bento/CSS Grid)
- JavaScript خالص (بدون مكتبات): IntersectionObserver للكشف عند التمرير، عدّادات أرقام، تنقل الجوال، تصفية المشاريع
- خط Cairo (Google Fonts) مع كل احتياطات الكتابة العربية (بدون letter-spacing، line-height مرتفع، أرقام غربية)
- خادم Node.js بسيط بلا اعتماديات خارجية (`server.js`) لخدمة الملفات الثابتة على Railway

## التشغيل محليًا

```bash
npm start
# يفتح على http://localhost:3000
```

## الهوية البصرية

|---|---|
| اللون الأساسي | كحلي إنشائي عميق `#04090F` / `#081426` |
| لون التمييز | كهرماني منجمي `#C68A1F` |
| الطباعة | Cairo (300–900) بتباين حجم مبالغ فيه للعناوين |

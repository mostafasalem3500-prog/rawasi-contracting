# رواسي للمقاولات العامة — صفحة هبوط ثنائية اللغة (سابقة أعمال)

> **ملاحظة:** هذا مشروع تصميمي (Case Study) بُني كسابقة أعمال لعرضها في منصات العمل الحر. اسم الشركة "رواسي" وجميع البيانات (المشاريع، الإحصائيات، الشهادات، بيانات التواصل) **بيانات افتراضية لأغراض العرض فقط** ولا تمثل كيانًا تجاريًا حقيقيًا.

## نظرة عامة

صفحة هبوط ثنائية اللغة (الإنجليزية هي الافتراضية، والعربية RTL كاملة) لشركة مقاولات عامة متخيّلة، مبنية بـ HTML/CSS/JS خالص بدون أي إطار عمل واجهي (framework-free) لضمان أعلى أداء ممكن. هوية بصرية "إنشائية مرتفعة" (Elevated Structural) مستوحاة من اتجاهات 2026: تسلسل هرمي مبالغ فيه للعناوين (Exaggerated Hierarchy)، تخطيط غير متماثل يكسر الشبكة عمدًا، نسيج حبيبي (grain) على الأقسام الداكنة، تصوير فوتوغرافي حقيقي معبّر لمواقع الإنشاءات بدل الأيقونات التجريدية، وطبقة حركة (motion) بمستوى استوديو مبنية على GSAP/ScrollTrigger.

**رابط الموقع المباشر:** https://rawasi-web-production.up.railway.app (الإنجليزية افتراضيًا) · النسخة العربية على `/ar/`

## البنية ثنائية اللغة

| المسار | اللغة | ملاحظات |
|---|---|---|
| `/` (`index.html`) | English (`lang="en" dir="ltr"`) | اللغة الافتراضية لزوار منصات العمل الحر الدولية، خط Manrope |
| `/ar/` (`ar/index.html`) | العربية (`lang="ar" dir="rtl"`) | نفس المحتوى والهوية، خط Cairo، اتجاه RTL كامل عبر Logical CSS Properties |

الصفحتان تشتركان في نفس `assets/css/style.css` و`assets/js/main.js`؛ كل صفحة تُعرّف بياناتها الخاصة (لغة الأرقام، نصوص النجاح، بيانات المشاريع الستة) عبر متغيرات عامة (`window.SITE_LOCALE`, `window.SITE_STRINGS`, `window.SITE_PROJECTS`) يقرأها `main.js` بدل الاعتماد على نسخة واحدة مُبرمجة داخليًا. مبدّل لغة (`.lang-switch`) في الرأس ينقل بين النسختين، وشريط علوي (`.case-study-bar`) يوضّح في كل صفحة أن الموقع دراسة حالة تصميمية مع رابط للكود المصدري على GitHub. `server.js` يخدم كل مسار من مساراته الصحيحة (بما في ذلك `/ar` و`/ar/` بلا امتداد ملف).

## الحركة والتفاعل (2026)

- **GSAP 3.13 + ScrollTrigger** (عبر CDN، مع بديل كامل بـ `IntersectionObserver` إن تعذّر تحميل المكتبة أو كان `prefers-reduced-motion: reduce` مفعّلاً) لكشف الأقسام عند التمرير وعدّادات الأرقام.
- **أزرار مغناطيسية** (`data-magnetic` + `gsap.quickTo`) على أزرار الدعوة الرئيسية — لأجهزة الماوس الدقيقة فقط.
- **ميل ثلاثي الأبعاد خفيف (3D tilt)** على بطاقات المشاريع عند تتبع المؤشر — لأجهزة الماوس الدقيقة فقط.
- كل حركة محكومة بـ `prefers-reduced-motion`، والمحتوى يبقى مرئيًا وكاملاً حتى لو فشل تحميل JavaScript.

## الأقسام

- رأس صفحة لاصق يختفي عند التمرير للأسفل ويظهر عند التمرير للأعلى، مع مبدّل لغة
- Hero بعنوان ضخم يتكشف سطرًا سطرًا + صورة موقع إنشاءات حقيقية بإطار مكسور الشبكة + عدّادات إحصائية متحركة
- شريط ثقة (Marquee) بالقطاعات المخدومة
- من نحن، خدماتنا (Bento Grid)، منهجية العمل (Timeline)، لماذا رواسي
- أعمالنا: شبكة مشاريع قابلة للتصفية حسب التصنيف، بميل ثلاثي الأبعاد تفاعلي
- آراء العملاء، الأسئلة الشائعة (Accordion أصلي عبر `<details>`)
- نموذج تواصل مع تحقق فوري من الحقول (تجربة أمامية فقط — بلا Backend فعلي)
- تذييل غني بالروابط والنشرة البريدية

## التقنيات

- HTML5 دلالي + CSS مخصص (Custom Properties، Logical Properties لدعم RTL، Bento/CSS Grid)
- GSAP 3.13 + ScrollTrigger (CDN، `defer`) مع بديل كامل بـ JavaScript خالص إن تعذّر التحميل
- خط Manrope للنسخة الإنجليزية وCairo للنسخة العربية (Google Fonts)، مع كل احتياطات الكتابة العربية (بدون letter-spacing، line-height مرتفع، أرقام غربية)
- خادم Node.js بسيط بلا اعتماديات خارجية (`server.js`) لخدمة الملفات الثابتة على Railway، مع دعم مسارات `/ar` و`/ar/` بشكل صحيح

## التشغيل محليًا

```bash
npm start
# يفتح على http://localhost:3000  (الإنجليزية)
# النسخة العربية على http://localhost:3000/ar/
```
